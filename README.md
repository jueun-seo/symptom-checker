# Symptom Checker

증상을 선택하면 알맞은 진료과와 해당 진료과에 대한 설명을 추천해 주는 웹 서비스입니다.
FastAPI + Jinja2로 만들었고, 깔끔한 Apple 스타일 UI를 적용했습니다.

## 주요 기능

- 6개 카테고리(통증, 소화기, 호흡기, 신경계·정신건강, 전신, 피부·비뇨생식기·감각기)의 증상을 아이콘 카드로 선택
- 여러 증상을 동시에 선택하면 중복 없이 진료과를 추천
- 추천된 진료과마다 설명과 주요 진료 분야 표시
- 진료과가 정해지지 않은 증상은 "AI 봇과 증상 관련 추가 대화 추천"으로 안내
- 다크모드 및 모바일 화면 지원

## 실행 방법

Python 3.12 이상과 [uv](https://docs.astral.sh/uv/)가 필요합니다.

```bash
uv run fastapi dev
```

브라우저에서 http://127.0.0.1:8000/symptom 으로 접속합니다.

## 프로젝트 구조

```
symptom-checker/
├── main.py                 # FastAPI 앱, 증상-진료과 매핑, 진료과 설명 데이터
├── pyproject.toml          # 의존성 설정
└── templates/
    ├── symptom.html        # 증상 선택 화면
    └── result.html         # 추천 결과 화면
```

## 엔드포인트

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/symptom` | 증상 선택 화면 |
| POST | `/result` | 선택한 증상(`symptoms`)을 받아 추천 결과 화면 반환 |

## 데이터 수정하기

`main.py`에서 데이터를 관리합니다.

- `symptom_mapping`: 증상 → 진료과 매핑. 새 증상을 연결하려면 항목을 추가합니다.
- `department_info`: 진료과별 아이콘, 설명, 주요 진료 분야. 새 진료과를 매핑에 추가하면 여기에도 같은 이름으로 추가해야 합니다.

## 안내

이 서비스는 참고용이며 의학적 진단을 대체하지 않습니다.
증상이 심하거나 응급 상황이라면 즉시 의료기관을 방문하세요.
